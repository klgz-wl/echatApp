## 明确保留的接口／产品缺口

1. **指定单集前 10 秒的真实素材关联**：现 Feed 仅有整剧及首个可用集的独立 preview，无法保证后台任意指定集或精确“正片前 10 秒”。客户端限时已做，不因此宣称素材契约已补齐。
2. **六位三类活动 Banner 配置**：现广告接口无类型、图片、活动路由和严格六位配置。客户端只展示实际可访问的广告及目标剧海报；如无广告则不制造推荐内容。
3. **简介**：现详情无 description。兼容可选真实字段；缺失显示明确空态，不替换成广告简介或 Figma 示例。
4. **评论／评价范围**：用户已确认评论可以模拟、无需后台。评论区现展示明确标识的示例评论，支持本地发送与关闭重开保留，空白禁发、输入上限500字，不产生网络请求或账号存储。完结评价仍仅本地界面且禁用提交；真实评价保存继续等待后端契约。
5. **币种与普通付费集**：正式解锁仍发送服务端规定的 coins，充值仍用既有钻石商品，不自行实现兑换。普通付费无 VIP 门槛与产品“所有非会员付费先订阅”的冲突尚需产品／后端确认；首页遇到无法对应的组合不静默扣费。
6. **历史**：当前 API 只支持恢复最后一集，不支持观看秒数、最近时间排序或整剧完结证明。
7. **范围说明**：字幕面板已从实际设计确认为 Subtitles，本版切换真实字幕轨道，不引入配音／多语言视频。榜单标题不承诺后端不具备的周榜统计。
