# 错误码对照

公共规范版本：`1.2.0`
发布日期：2026-11-02
配套文件：[错误码接入规范](错误码接入规范.md)、[通用实施提示词](通用实施提示词.md)、[版本清单](版本清单.json)。

本表是跨项目共用的编号字典，只定义语义和使用边界。品牌、包名、环境、资源名、源码入口和验收结果由各项目的接入记录维护。接收到本表不表示项目已完成代码接入，也不要求补建项目不存在的功能。

用户可见错误保留原文，在末尾追加一个 ASCII 空格和括号中的编号，例如 `Please try again. (E-501)` 或 `Please try again. (R201)`。详细展示、映射和维护要求见配套接入规范。

## E 系列：业务和界面诊断

E 系列表示业务或界面场景，不等于后端业务 code、HTTP 状态或精确根因。同一场景复用同一码，不能根据英文文案是否相同直接合并不同场景。

| 错误码 | 统一语义 | 使用边界 |
| --- | --- | --- |
| E-201 | 未同意服务条款或隐私政策，认证被阻止 | 沿用项目现有协议校验和提示时机 |
| E-202 | 账号输入校验失败 | 具体长度、字符等规则由项目现有需求决定 |
| E-203 | 密码输入校验失败 | 具体校验规则由项目现有需求决定 |
| E-204 | 用户主动提交账号密码或一键匿名认证失败 | 不用于地区检查失败；不改变认证接口和失败恢复流程 |
| E-205 | 会话启动恢复、首次资料初始化或其他未分类启动失败 | 仅限启动阶段，不能作为全应用的通用未知错误码 |
| E-206 | 会话恢复或主动认证前检测到网络不可用 | 不泛化到所有业务断网；地区阶段使用真实 R200 |
| E-207 | 业务操作期间会话已失效、已退出或身份发生变化 | 仅用于原流程已向用户提示需重新认证的场景；启动恢复和主动认证失败仍分别使用 E-205、E-204，不改变会话清理、刷新、路由及账号隔离 |
| E-301 | 本机图片读取、下载或私有副本准备失败 | 对应图片准备动作失败；媒体展示失败使用 E-302 |
| E-302 | 图片、动图或视频媒体无法加载或播放 | 保留原媒体重试、列表和播放状态 |
| E-303 | 协议或支付网页主页面加载失败、超时、SSL 失败，或无法打开支付浏览器 | 子资源失败是否影响主页面沿用现有判断，不一律升级为整页失败 |
| E-304 | 设备没有可处理联系邮件的应用 | 不要求新增联系入口 |
| E-305 | 图片选择或拍照入口不可用，或本机拍摄无法完成 | 仅用于原流程已展示的入口启动或拍摄失败；不将用户正常取消选择／拍摄判为错误；取得图片后的读取、下载或私有副本准备失败仍用 E-301 |
| E-401 | 生成任务已进入明确失败终态 | 超时、状态未知和刷新失败不能据此标记任务终止 |
| E-402 | 提交请求结果未知，重试需要检查原请求 | 保持原请求关联及幂等，不因展示编号重新建任务 |
| E-403 | 任务状态刷新失败 | 任务仍可能继续；不改变终态和轮询规则 |
| E-404 | 任务已完成但结果媒体缺失或不可用 | 不把任务重写为失败终态 |
| E-405 | 余额不足，需要进入已有购买流程 | 不新增商品或改变余额、价格及权益规则 |
| E-406 | 生成请求与已有提交发生明确冲突 | 例如同一请求标识的参数不一致；保留原请求及幂等关联，不将结果未知、处理中或任务失败当作请求冲突 |
| E-407 | 生成服务或当前生成模式暂不可用 | 仅用于原流程已明确归类的生成可用性提示，包括所需报价不可用；保留原禁用、重试和价格校验，不回退默认价格，不据此判定任务失败或提交结果 |
| E-408 | 生成源图或其他生成输入资源上传失败 | 仅限输入资源上传阶段，不能仅因上传连接异常、超时或响应无效就认定生成请求已提交或任务失败；本机准备失败用 E-301，头像更新失败核对 E-705 |
| E-409 | 生成请求在准备或创建阶段被明确阻止、拒绝，未形成可用任务 | 例如输入缺失／不匹配或已确认未提交的本地发起失败，以及服务端明确拒绝创建；须有尚未提交或明确拒绝的证据。已有会话、余额、冲突和服务可用性语义优先使用对应专码；是否受理不明用 E-402，真实任务失败终态用 E-401 |
| E-501 | 分类、照片列表、作品、商品或交易记录等内容加载失败 | 根据真实内容加载入口映射，不吞并其他明确业务错误 |
| E-601 | 支付失败，或已有结果明确表示支付流程未完成且需要失败提示 | 不把待确认、用户取消、单纯关闭页面或未知支付结果直接判为失败 |
| E-602 | 支付待确认或履约仍在等待 | 诊断状态，不是失败终态；仅在原流程已展示此提示时追加 |
| E-603 | 用户取消支付 | 诊断状态，不等同支付失败；仅在原流程已展示此提示时追加 |
| E-701 | 举报提交失败 | 不将模拟成功改成真实服务，缺少接口仍按项目现有范围处理 |
| E-702 | 退出登录请求失败 | 保留原会话与失败后的重试行为 |
| E-703 | 注销账号请求失败 | 保留原会话、确认及重试行为 |
| E-704 | 个人资料输入校验失败 | 例如昵称长度或格式不符合既有要求；不借用账号认证输入的 E-202，不改变校验规则 |
| E-705 | 个人资料保存、更新失败，或本次更新能力不可用 | 例如昵称保存、头像上传或更新失败；仅限资料修改动作，资料读取用 E-501，本机图片准备用 E-301，已明确的业务会话失效用 E-207；不改变保存、上传、回滚或会话行为 |

E-602、E-603 沿用既有诊断编号，不因归入本表新增 Toast、业务失败事件或支付状态转换。成功、普通操作、加载中及普通空态不附诊断码。

业务响应 code 或 HTTP 401／403、409、503 只能结合接口契约和原有分类作为映射证据，不能直接与 E-207、E-406、E-407 画等号。普通权限不足不自动视为会话失效；处理中或提交结果未知不自动视为冲突；连接异常或超时不自动视为服务不可用。同一既有展示分支覆盖多个触发条件时，应核对实际语义，不为编号改变受理结论、重试和任务状态。

新增场景按动作和阶段分流：图片选择／拍摄入口失败使用 E-305，取得图片后的本机准备失败仍使用 E-301；生成输入资源上传失败使用 E-408，头像上传或资料保存失败核对 E-705，资料输入不合法使用 E-704。共享文案不能把这些场景统一归入 E-301、E-202 或 E-501。

生成阶段仅在确定尚未提交或明确拒绝创建时使用 E-409；请求可能已发出而受理结果不明时使用 E-402。任务列表中的本地失败记录、失败状态枚举或缺失 taskId 本身不能证明服务端任务已失败，也不能单独证明请求未受理；须结合原有阶段、请求关联和服务端结果判断。E-408、E-409 都不授权重建幂等键、重复提交、改变任务状态或新增重试。

## R 系列：地区准入诊断

R 系列由地区检查的真实结果决定，不根据显示文案、混淆后的异常类名或猜测选择。同一地区错误只追加一个实际 R 码，不叠加 E 系列编号。

| 错误码 | 统一语义 | 使用边界 |
| --- | --- | --- |
| R101 | 默认 SIM 国家／地区命中受限名单 | 名单、信号优先级沿用项目规则 |
| R102 | 系统区域命中受限名单 | 不按界面语言猜测地区 |
| R103 | IP 国家／地区命中受限名单 | 必须取得有效地区结果 |
| R200 | 无网络、无 Internet 能力或已识别 Captive Portal | 只表示地区入口的网络判断，不改地区重试策略 |
| R201 | 地区查询 DNS 失败 | 使用已有明确分类 |
| R202 | 地区查询超时或 IO 中断 | 正常协程取消单独传播，不能转换成用户错误 |
| R203 | 地区查询 TLS 或证书异常 | 不显示证书或原始异常内容 |
| R204 | 地区查询其他 IO、连接或读取失败 | 已有更具体分类时不降级到此码 |
| R205-数字 | 地区服务返回非 2xx HTTP 状态 | 例如 R205-403、R205-429；仅附数值状态，不改变跳转策略 |
| R206 | 地区响应 JSON 无效、非对象、缺少 country 或其类型不是字符串 | 不展示响应正文 |
| R207 | country 为空或不是有效 ISO 国家／地区码 | 不把无效地区当作可放行结果 |
| R299 | 其他无法归类的地区异常 | 仅限地区检查；不能代替所有业务未知错误 |

R205-数字 是一个参数化编号类别，数字来自真实 HTTP 状态，不需要为每个状态新分配编号。其余 R 码为固定值；不能将任意服务端字符串直接作为诊断码显示。

## 编号维护

1. 本版登记 30 个 E 系列编号和 12 类 R 系列编号，已发布编号的语义保持稳定，废弃编号保留且不复用。
2. 相同语义跨项目共用同一码；各项目按实际功能接入，不存在的入口记为不适用，不新增功能凑齐编号。
3. 新场景先提交触发条件、业务语义、现有候选码及无法复用的原因，由公共主版本维护者统一分配，发布新版本后再同步各项目。多个实施者不能自行占用下一个数字。
4. 未取得新公共版本时，将未覆盖场景记为待分配、待接入；不能临时造码、滥用兜底码，或把这部分报告为全部完成。
5. 公共表不记录项目资源或测试结果。版本发布、同步及项目记录要求见[错误码接入规范](错误码接入规范.md)。

## 1.2.0 变化与迁移

本版在 `1.1.0` 基础上新增 E-305（图片选择／拍照入口或本机拍摄失败）、E-408（生成输入资源上传失败）、E-409（生成请求在准备或创建阶段被明确阻止／拒绝）、E-704（个人资料输入校验失败）、E-705（个人资料更新失败或不可用）。原有 25 个 E 系列编号和 12 类 R 系列编号的编号、语义及使用边界保持不变，原文正文后缀规则保持不变。

升级时整组同步四文件并校验清单，重点核对共享错误文案、图片获取与准备、生成输入上传与创建、资料校验与更新的实际触发阶段。记录旧码（原未带码记为无）、公共码和迁移状态；对不能确认提交结果的入口保留 E-402 边界，不因新增 E-409 迁移为明确失败。仅同步文档仍记为待接入，旧版本和 ZIP 不覆盖。

## 1.1.0 历史变化与迁移

本版在 `1.0.0` 基础上新增 E-207、E-406、E-407。原有 22 个 E 系列编号和 12 类 R 系列编号的编号、语义及使用边界保持不变，原文正文后缀规则保持不变。

升级时整组同步四文件并校验清单，按实际入口核对新增码的适用性，记录旧码（原未带码记为无）、公共码及迁移状态。仅同步文档的项目仍记为待接入；其余未盘点入口继续待核对，不能据此宣称全量覆盖。
