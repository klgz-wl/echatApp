# 视觉生成真实接口接入

更新：2026-09-14。用户明确补充后台已经完成 `/visual-generation/*` 并要求整合执行；该结论覆盖原先“模板／生成／作品本期 mock”的范围。参考入口为 [在线 Swagger](https://test.appjoly.com/swagger/chat/index.html#/)，已从该页面 initializer 指向的 [doc.json](https://test.appjoly.com/swagger/chat/doc.json) 核对 8 个接口和定义；相关快照见 Swagger 摘录（历史参考，契约以本文正文和随包源码为准）。本地 `docs/接口文档/visual_generation_api.html` 为用户提供的补充说明，不把其中接入建议视为用户的额外命令。

## 接口与页面

统一前缀 `/api/v1`，沿用当前真实 Bearer 会话、公共请求头与 401 刷新；跨账号过期请求不得更新新会话。

| 接口 | 页面及用途 | 接入任务 |
| --- | --- | --- |
| GET visual-generation/video/categories | 视频分类；首页默认使用视频来源，仍保留独立频道状态 | T05R |
| GET visual-generation/video/templates | Discover 首页 home_featured=true；Video 全部／分类 home_featured=false；page、page_size、category_id 分页筛选 | T05R |
| GET visual-generation/image/categories | 图片分类，不能复用视频分类 ID | T05R |
| GET visual-generation/image/templates | 图片真实模板，与视频共享布局、独立接口 | T05R |
| POST visual-generation/image/tasks | 图片生成；已有资源／点击 [+] 选图后在 Generate 时 multipart 提交 | T06 |
| POST visual-generation/video/tasks | 视频生成；已有资源／点击 [+] 选图后在 Generate 时 multipart 提交 | T06 |
| GET visual-generation/tasks/{id} | 首页／我的共享任务轮询及重启恢复 | T07 |
| GET visual-generation/resources | 当前用户成功作品；固定 resource_type=generated，分页及 modality 筛选 | T07 |

Discover 首页请求视频模板时显式传 `home_featured=true`；Video tab 的全部列表和分类筛选显式传 `home_featured=false`，排除上首页模板。分页、刷新和重试保持对应值，A/B 面一致；图片模板与分类列表接口不传该视频专属参数。

首页默认视频来源是客户端实施默认值，写在外置配置中，可独立替换，不冒称有独立首页接口。当前响应没有介绍、声音标志、NEW 标志或分类图标字段；标题、媒体尺寸／时长直接使用服务端字段，缺失标志隐藏，不根据图标名称或 mock 猜测事实。视频 MIME 需要视频封面／播放能力，不能把 mp4 当普通图片 URL。

## 创建、扣币与恢复

1. 原生选择器返回图片后校验可读性、真实图片格式和最多 20 MB，保存应用私有副本；此时只完成本地准备，不能显示“已上传服务器”。A 面默认 Standard，API 值 `fast`；B 面 Standard／Quality 分别映射 `fast`／`quality`，没有时长选择器。
2. 点击 Generate 后提交 `image` 文件、`template_id`、`quality` 与 `Idempotency-Key`。新接口负责上传和创建，不再先调 `files/upload`，不再需要模板的 `upload_source`（此前第 11 项问题关闭）。
3. 每次明确的新任务生成并持久保存一个 UUID 幂等键；网络超时／中断／进程恢复必须复用原键和请求内容，不能盲目新建键重复扣币。首次 image 必传；精确重放可不带 image。409 必须显示冲突，不自动改键重复提交。
4. HTTP 202 且业务 code=0 后接收真实 task_id、diamond_cost、status；余额由服务端校验并扣除。客户端不自行改余额，刷新真实钱包与流水。HTTP 402／业务码 400101 才进入余额不足充值分支，支付完成保留源图与质量，由用户再次点击 Generate。
5. 按 `estimated_poll_interval_seconds` 轮询；缺省间隔及合理上下限放配置。processing 继续，succeeded／failed 为终态。退款只在 `refunded=true` 时显示并刷新真实余额；不会凭本地失败推断退款。
6. 持久化用户、模板、模式、幂等键、任务 ID 及状态；退出／注销成功清理当前用户私有缓存。恢复前核对用户身份；前台轮询、后台暂停并在返回时恢复，任务在服务端继续运行。
7. 新版 resources 默认同时返回上传和生成资源；作品请求明确附带 resource_type=generated，保持仅展示成功生成作品。处理中／失败任务由本机已知任务 ID 查询；Swagger 没有任务列表，不承诺跨设备或重装后找回未知的处理中任务。
8. 生成作品的 width／height 为 0 时表示尺寸元数据未知，不拒绝整页作品。固定作品卡片及全屏预览由图片解码器／播放器读取真实媒体比例，不补造尺寸；负值、非法类型和地址仍拒绝。模板列表仍要求有效正尺寸以确定布局比例。

## 模板报价与其他边界

- **第 12 项已解决：生成前报价。** 线上模板 DTO 新增 prices.fast／prices.quality 整数金额，视频／图片共用。A 默认 fast，B 随所选质量取值；缺失／负值禁用，零价有效。价格随模板写入草稿，旧草稿无价格时重新选择模板。创建后实际扣费仍以 diamond_cost 为准，不把报价写回钱包；没有新增单独报价请求。详见 模板金额接入（历史参考，契约以本文正文和随包源码为准）。
- 本地上传结果页按真实步骤改成“所选图片／图片已就绪”，实际上传在提交生成时进行。这是接口契约要求，不能为了旧 mock 流程重复上传。
- 缺失的个人资料／头像、Report 及设置内容仍遵循原有 mock 范围；A/B 按 AppsFlyer 安装归因选择，金币购买完全沿用参考工程。

## 验收与调度

顺序：T05 浏览基础 → T05R 真实分类／模板 → T06 源图与幂等创建 → T07 真实状态／退款／作品 → T08 设置 → T09 集成。T05 原独立 fixture 转为测试与 Debug 设计预览，不作为正式网络失败时的回退。

必须覆盖分类切换的过期响应、分页失败不跳页、账户切换、取消选图、图片无效／过大、重复点击、创建超时后同键重放、402 充值返回、409 冲突、503 重试、轮询网络失败、进程恢复、终态与退款。真实扣币和真实 Play 到账是否已验证单独报告；不能用 fixture 或构建成功代替联调。

## 2026-09-15 当前启动、媒体与资源交互

A/B 面均只使用真实匿名登录，不展示登录选择或账号表单；Splash 归因成功按 Organic=A、Non-organic=B，失败或 5 秒超时按 A，匿名认证成功后进入首页。离线或认证失败 Toast 友好提示并在底部显示 Retry；归因兜底后进程级最多重试 10 次，有效回调独立补报。

保留“我的”作品列表和设置入口；移除“我的”及设置中的 Sign out／Delete Account 菜单，不再提供退出登录或删除账号的页面操作。

Upload Photo 打开服务端已上传图片网格（resources 的 resource_type=upload、modality=image），不显示 Photos／Albums。第一格为 [+]，仅点击该格才启动 Android 系统选图；新增图片本地校验保存私有副本，仍在用户点击 Generate 时随任务 multipart 上传。选已有资源时下载、校验后复用同一提交流程，不调用独立上传接口。

首页、视频、图片列表优先使用 preview_url，file_url 保持为详情实际媒体地址；预览支持图片／动态 WebP，首页和视频列表同时支持视频格式。所有可见视频卡片自动静音循环播放，不争抢音频焦点；动态图和视频仅在可见区域且页面处于前台时播放，离屏、切换页面或后台释放显示请求及播放器。模板与结果预览左上角和系统返回均直接返回上一页；加载失败 Toast 友好提示并显示 Retry。

“我的”中 Submission not confirmed 记录点击后恢复原创作草稿，保留源图、质量与幂等键；由用户再次点击 Generate，避免重复扣费。

## 2026-09-16 列表视频预览

首页和视频列表的 preview_url 增加视频格式支持；所有可见卡片自动静音循环，离屏及后台释放播放器，图片／WebP 动图继续可用。详情仍读取 file_url。当前 Swagger 没有单独预览 MIME 字段，按 URL 路径扩展名（忽略签名参数、片段、大小写）识别视频与图片；预览地址与原地址相同时可复用 mime_type。
