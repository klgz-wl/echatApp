## 展示与证据约定

- 唯一后缀格式化入口：[ErrorDiagnostic.kt](../app/src/main/java/yumo/achat/app/ui/error/ErrorDiagnostic.kt)，通过 `withDiagnosticCode`、`Context.diagnosticMessage` 和 Compose `diagnosticString` 共享格式化逻辑；格式资源为 `error_with_code`。保留原语言和安全正文，末尾恰好一个 ` (编号)`。
- 专属静态带码资源与动态 formatter 不能叠加；检查重复格式化、fallback 替换和格式参数后缀的位置。普通 Retry、成功、加载、空态不附码；仅表达确定错误的局部短提示纳入映射，例如 局部 `diagnosticString(..., "E-302")`。
- 动态正文先经现有安全展示边界，不安全内容回到场景 fallback；禁止原始异常、URL、响应正文、凭据和用户标识成为错误提示。编号由语义证据决定，不能由显示正文反推全部分类。
- 生成分类入口为 [GenerationDiagnostic.kt](../app/src/main/java/yumo/achat/app/ui/imagevideo/GenerationDiagnostic.kt)。本机准备使用 typed `ImagePreparationException`，生成输入上传使用 E-408；明确未提交或明确业务拒绝创建使用 typed 证据映射 E-409。业务响应 `code=409/503` 按生成契约分别映射 E-406/E-407，不是全局 HTTP 409/503 映射。
- 缺 taskId、本地失败枚举、连接超时或解析失败不能证明未受理或服务端任务失败。请求可能已发出且结果未知时保留 E-402 与原幂等关联；只有服务端 `status=failed` 使用 E-401。
- 支付纯 CLOSED、超时、创建/确认未知的既有提示使用 E-602；明确用户取消使用 E-603，明确支付失败使用 E-601，网页/浏览器失败独立使用 E-303。不新增通知、失败事件或状态转换；不改变查单、价格、恢复及履约协议。
- 仅给既有可见业务会话失效/身份变化提示映射 E-207。普通 403 权限拒绝不等于会话失效，原本静默的账号切换和取消继续静默。
